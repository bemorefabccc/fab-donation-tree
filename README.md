# FAB Donation Tree

The live FAB Donation Tree for Bemorefab Children's Cancer Charity (registered charity 1209136).

Live tree: https://bemorefabccc.github.io/fab-donation-tree/

- `index.html` is the whole tree page. GitHub Pages shows it, and the Bemorefab website shows it on the homepage and the FAB Donation Tree page.
- When a business buys a bauble, Claude adds it to the master copy in the "Donation Tree / Tree kit (for Claude)" folder, runs `make_site.py`, and replaces `index.html` here. The tree updates within about 10 minutes, and the website shows the new tree by itself.
- Please don't edit `index.html` by hand.
